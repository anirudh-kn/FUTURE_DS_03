# 📊 Customer Conversion Funnel Dashboard

## 📌 Overview

This project presents a **Customer Conversion Funnel Dashboard** built using Power BI. It analyzes how users move through different stages of a marketing funnel and identifies key drop-off points to improve business performance.

---

## 🎯 Objectives

* Analyze customer journey from Visitors to Customers
* Identify stages with highest drop-off
* Compare performance across different marketing channels
* Provide actionable insights and recommendations

---

## 📁 Dataset

The dataset used for this project is:

* `marketing_funnel.csv`

It contains:

* Stage (Visitors, Leads, Prospects, Customers)
* Channel (Paid Ads, Social Media, Email, Organic Search)
* Count of users

---

## 📊 Dashboard Features

### 🔹 KPI Cards

* Total Visitors
* Total Leads
* Total Customers
* Conversion Rate

### 🔹 Funnel Analysis

* Visual representation of customer journey
* Highlights drop-off at each stage

### 🔹 Channel-wise Performance

* Comparison of Leads, Prospects, and Customers across channels

### 🔹 Interactive Filter

* Channel slicer for dynamic analysis

### 🔹 Insights & Recommendations

* Key observations and business suggestions included

---

## 📈 Key Insights

* Highest drop occurs from **Leads to Prospects**, indicating weak engagement
* Overall conversion rate is **~5.4%**, suggesting improvement opportunity
* **Paid Ads generate highest traffic** but moderate conversion efficiency
* **Organic Search shows better quality leads** with stable conversion
* Funnel narrows significantly at final stage

---

## 💡 Recommendations

* Improve **lead nurturing strategies** (email campaigns, follow-ups)
* Optimize **landing pages** to reduce drop-off
* Focus on **high-converting channels** like Organic & Email
* Implement **retargeting strategies**
* Enhance **customer conversion techniques** (offers, personalization)
